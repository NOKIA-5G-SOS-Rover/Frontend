# Final interaction fixes

- Critical alert now spans the full viewport width so the magenta gradient begins at the absolute left edge.
- Removed the detached pulse/tab marker before the critical-event copy.
- Direction pad contains only forward, left, backward, and right controls; backward is centered between left and right.
- Speed uses a 0–100% range with −10%, Reset, and +10% controls.
- Reset returns speed to 50%.
- Double-click the displayed percentage to type a value; Enter or blur applies it, Escape cancels, and values are clamped to 0–100.
- Arrow-key driving is ignored while typing in the speed input.
